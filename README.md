## Enquiry form activation
The enquiry form uses FormSubmit, a third-party form delivery service. The destination is set to `delegendtech@gmail.com`. Before relying on it publicly:
1. Publish the site to a test URL.
2. Submit a test enquiry using a different email address.
3. Open the confirmation email sent by FormSubmit to `delegendtech@gmail.com` and approve the activation.
4. Submit a second test and confirm the enquiry arrives.
5. Review FormSubmit's current privacy terms before collecting customer information. Never ask customers to submit passwords, card details or other sensitive information.

Until the form is tested and activated, customers can contact the business directly by email or WhatsApp.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Create a GitHub repository (for example, `delegend-enterprise`).
3. Upload the contents of this folder to the repository root. `index.html` must be at the top level.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
6. Wait for GitHub Pages to publish and use the URL shown in Settings → Pages.
